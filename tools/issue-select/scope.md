# Scope

## Target repository

Repo: codepath/pathreview-ai301-fa26-s1

## What counts as a valid candidate issue

- Must be an open issue in the target repository above.
- Must not already have a merged PR that closes it.
- Must not have an active assignee who is not you.

## Contribution policy

This is a course sandbox repo. Classmates are not strangers — the course is the coordination
channel. A classmate's earlier comment expressing interest does **not** block you from taking
the issue; credit attaches to the PR you open, not to a comment. Do not comment to claim the
issue until Unit 2 teaches you how to write the claim comment.

Already-claimed check applies only to:
- A GitHub assignee set on the issue.
- An open, unmerged PR that is linked to the issue and was opened in the last 14 days.

## Out of scope

- Issues in repositories other than the one above (in eval mode the harness supplies snapshots
  from other repos; grade them as-is against the rubric — the scope repo line does not filter
  eval snapshots).
- Issues labeled `wontfix`, `duplicate`, or `invalid`.
- Issues that are actually feature requests with no reproduction steps or specification.
